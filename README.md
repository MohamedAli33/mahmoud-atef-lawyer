# Mahmoud Atef — موقع شخصي (محامي)

صفحة واحدة (`index.html`) مبنية بـ HTML/CSS/JS خام، من غير أي أدوات بناء، بنفس أسلوب مشروع البورتفوليو التاني عندك.

## المعاينة محلياً

```bash
python -m http.server 8933
```

وبعدين افتح `http://localhost:8933` في المتصفح. أو افتح `index.html` مباشرة (الصفحة شغالة من غير سيرفر كمان).

## الملفات

- `index.html` — الصفحة كلها (المحتوى والتنسيق والسكريبت في ملف واحد). عربي وإنجليزي، والعربي هو الافتراضي.
- `images/mahmoud-atef.jpeg` — صورته، من واتساب، بمعالجة duotone (كحلي/دهبي) في الـ CSS.
- `Mahmoud-Atef-CV.pdf` — نفس ملف الـ CV الأصلي، وده اللي بينزل لما حد يدوس على زرار "تحميل السيرة الذاتية".
- `images/cert-*.jpg` — صور الشهادات السبعة (دبلوم، بكالوريوس، 4 شهادات تدريب، خطاب خبرة)، ظاهرة في قسم "المستندات والشهادات" تحت المؤهلات، كل واحدة بتتفتح في نافذة منبثقة (modal) فيها الصورة كاملة + الجهة المانحة + التفاصيل.

**ملاحظة أمان:** شهادتي الدبلوم والبكالوريوس كانت فيهم الرقم القومي كامل وواضح، فغطّيته (redaction) في الصورتين قبل ما أحطهم على الموقع — الرقم القومي بيانات حساسة متنفعش تتنشر على موقع عام.

## المحتوى

كل حاجة في الصفحة (الخبرة، الشهادات، المهارات، الكتاب) منسوخة بالحرف من `Mohamoud_Atef_CV.pdf` ومترجمة للعربي بنفس المعنى. ملخص السيرة اتعاد صياغته بأسلوب موقع شخصي بدل أسلوب "أبحث عن وظيفة"، بس المعلومات نفسها. تاريخ ميلاده اتسيب برا الموقع لأنه مش لازم يظهر لأي زائر.

## اللغتين

زرار "English / العربية" فوق شمال بيبدل كل نص في الصفحة، واتجاه الصفحة (يمين لشمال / شمال ليمين)، وعنوان التبويب، وdescription الصورة — كله بجافاسكريبت بسيط من غير إعادة تحميل. اختيار اللغة بيتحفظ في المتصفح (localStorage) فلو رجع الزائر تاني بيلاقي نفس اللغة.

## زرار تحميل الـ CV

على الموقع الحقيقي (بعد الرفع على Netlify) الزرار بيحمّل ملف `Mahmoud-Atef-CV.pdf` مباشرة زي أي رابط تحميل عادي.
على نسخة المعاينة (claude.ai) — لو فتحته من نفس اللينك اللي بعتهولك — الموقع بيستخدم صلاحية تحميل خاصة ببيئة كلود عشان يشتغل الزرار هناك كمان (هيسألك تأكيد قبل ما ينزّل الملف، ده طبيعي).

الريبو اتعمل واتدفع فعلاً على حسابك:

باقي خطوة وحدة بس، وهي ربطه بـ Netlify (محتاجة تسجيل دخولك، فمش قادر أعملها من هنا):

1. افتح اللينك ده وهو هيجهزلك الريبو جاهز:
   [app.netlify.com/start/deploy?repository=https://github.com/MohamedAli33/mahmoud-atef-lawyer](https://app.netlify.com/start/deploy?repository=https://github.com/MohamedAli33/mahmoud-atef-lawyer)
2. سجّل دخولك بنفس حساب GitHub بتاعك لو طلب منك، ووافق على الصلاحية.
3. مفيش build command ولا build directory تحتاج تغيّرها — سيبها فاضية واضغط **Deploy site**.
4. Netlify هيديك سب-دومين مجاني تلقائي زي `mahmoud-atef-lawyer.netlify.app` (تقدر تغيّر الاسم من Site settings → Change site name).

بعد كده أي `git push` جديد على الريبو ده هيرفع الموقع تلقائي، زي مشروعك التاني بالظبط.
